# Third-party notices

This project is a **port of Vega and Vega-Lite to Kotlin**, verified against the
upstream implementations rather than against its own expectations. Both the code
and the fixtures therefore derive from other people's work, and this file records
whose, under what terms, and which parts of this repository are involved.

## Vega, Vega-Lite, and the `vega-*` packages

**BSD 3-Clause** — Copyright (c) 2015-2023, University of Washington Interactive
Data Lab.

What derives from them:

- **The engine.** `vega-model`, `vega-expression`, `vega-dataflow`, `vega-scale`
  (within `vega-dataflow`), `vega-scene`, `vega-svg` and `vega-runtime` are
  translations of Vega's own algorithms, defaults and naming. `vega-lite` is a
  translation of the Vega-Lite compiler. Where the source comments name a
  function — `resolveSpan`, `getSort`, `parseFacetHeader`, `moveFacetDown`,
  `getCardinalityAggregateForChild` — that is upstream's function, and the code
  beside the name follows it deliberately.
- **`test-fixtures/reference/`** and **`test-fixtures/vega-lite-reference/`** —
  scenes and specifications produced by running upstream Vega 6.3.1 and
  Vega-Lite 6.4.3. **Committed**, and regenerated by `scripts/oracle.sh` and
  `scripts/vega-lite-oracle.sh`.
- `test-fixtures/upstream-vectors/*.json` — test vectors recorded from the suites
  of `vega-crossfilter`, `vega-encode`, `vega-event-selector`, `vega-expression`,
  `vega-force`, `vega-format`, `vega-functions`, `vega-geo`, `vega-hierarchy`,
  `vega-label`, `vega-regression`, `vega-scale`, `vega-scenegraph`,
  `vega-statistics`, `vega-time`, `vega-transforms` and `vega-voronoi`. These are
  **not redistributed here** — they are gitignored and rebuilt locally from the
  pinned packages — but the ported code was written against them, so the
  attribution stands either way.

## d3 and TopoJSON

**ISC** — Copyright 2010-2023 Mike Bostock.

Vega is built on d3, so a port of Vega is a port of the d3 it uses. What derives
from them:

- **Scales, ticks, formatting, colour interpolation, geographic projections and
  paths, shape and curve generation, CSV/TSV parsing, hierarchy layouts** —
  ported into `vega-dataflow` and `vega-scene` from `d3-scale`, `d3-array`,
  `d3-format`, `d3-time`, `d3-time-format`, `d3-color`, `d3-interpolate`,
  `d3-geo`, `d3-path`, `d3-shape`, `d3-dsv`, `d3-hierarchy` and
  `topojson-client`.
- `test-fixtures/upstream-vectors/*.json` — test vectors recorded from the suites
  of `d3-array`, `d3-color`, `d3-dsv`, `d3-format`, `d3-geo`, `d3-hierarchy`,
  `d3-interpolate`, `d3-path`, `d3-scale`, `d3-shape`, `d3-time` and
  `d3-time-format`. Gitignored and rebuilt locally, as above.

## vega-datasets

**BSD 3-Clause** — Copyright (c) 2015-2023, University of Washington Interactive
Data Lab. Same text as Vega's, above.

The 27 files in `test-fixtures/data/` are from `vega-datasets`, so that the two
engines read the same bytes when their output is compared.

**One thing to check before relying on this.** `vega-datasets` is BSD 3-Clause
*as a collection*, and its own documentation notes that individual datasets come
from elsewhere and carry their own provenance — `movies.json` is the one upstream
flags explicitly. This file does not attempt to settle each dataset's origin, and
nobody should read it as having done so.
